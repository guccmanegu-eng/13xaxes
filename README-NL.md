# Dutch (NL) for 12 Axes
Copy every file in this folder over the same path in your repo (replace existing files), then commit and redeploy backend + frontend.
- New: backend/src/main/resources/data/i18n/nl/*.json (all questions, axes, ideologies, countries, figures in Dutch)
- Updated backend: accepts lang=nl (falls back to English for a few small generated phrases)
- Updated frontend: Dutch UI text, PT/EN/NL dropdown picker, ?lang=nl, Dutch browsers default to NL
Note: the separate static ideology/country/person pages stay PT/EN; from Dutch they link to English.
Translations are machine-made — worth a quick read by a Dutch speaker.
